# Aviso sobre o dataset

Este projeto usa o MedMNIST (pneumoniamnist) como dataset de treino.
Os proprios criadores do MedMNIST classificam esse dataset como
material de benchmark/pesquisa, NAO recomendado para uso clinico real.

O Sinapse Protocol e uma prova de conceito de infraestrutura de
coordenacao de aprendizado federado. Nao e uma ferramenta de
diagnostico medico e nao deve ser apresentado como tal.
